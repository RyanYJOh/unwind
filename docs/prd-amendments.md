## 2026-08-07 (3차 — 디자인 개편, 롤백 가능)
kRoomDesign 상수 한 줄로 이전 형광등 디자인 롤백 가능 (design_variant.dart).
| 항목 | 내용 |
|---|---|
| 광원 | 우측 상단 천장 조명(갓+전구, 잉크 아웃라인) — 방의 유일한 광원. 조도(1-t)에 비례해 감쇠, 전등 줄이 그 아래 |
| 아이템 | 형광등 패널 → 담백한 벽 스위치 행. 끄면 천장 조명이 어두워지고 화면이 라이트→다크 |
| 도미노 | 순차 소등 시 각 항목 마이크로 바운스(240ms, 0.945→1.03→1) |
| 기타 | ITSAppUsesNonExemptEncryption=false (수출 규정 질문 제거) |
